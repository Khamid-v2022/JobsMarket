# Domain Map

## Bounded Context

### 1. Identity

- Sign-up, sign-in, social login
- Sessions, password lifecycle, 2FA
- RBAC, policies, admin roles

### 2. User

- Shared account model
- Talent Profile
- Client Company / Team
- Verification status, portfolio, preference settings

### 3. Marketplace

- Job posting
- Category / Skill taxonomy
- Search / Filter / Saved search
- Recommendations and personalization

### 4. Proposal

- Proposal authoring
- Screening question responses
- Invitations, interviews, shortlisting
- State transitions

### 5. Contract

- Hourly / Fixed-price contract
- Milestone
- Work submission, approval, cancellation
- Dispute-ready evidence data

### 6. Billing

- Payment methods
- Escrow
- Fees
- Settlement / payout
- Ledger

### 7. Messaging

- Conversations
- Attachments
- Read receipts
- System event messages

### 8. Review

- Mutual reviews
- Public/private feedback
- Trust score aggregation

### 9. CMS

- Marketing pages
- Blog
- FAQ / policy docs

### 10. Admin

- User/job/contract operations
- Risk detection
- Abuse reports and moderation
- Manual refunds/adjustments
